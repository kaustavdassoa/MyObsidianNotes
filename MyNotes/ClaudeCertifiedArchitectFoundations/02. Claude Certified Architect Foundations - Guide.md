# Everything You Need to Know Before You Register, How to Prepare, and What to Expect on Exam Day

On March 12, 2026, Anthropic launched a proctored, architecture-level certification — the **Claude Certified Architect, Foundations (CCA-F)** — backed by a $100 million investment in partner enablement. 

This is a closed-book, proctored, scenario-based exam testing architectural decisions for building production-grade Claude systems at enterprise scale.

---

## 🎯 What Exactly Is the CCA-F?
The CCA-F is Anthropic’s first official technical credential, sitting at the entry point of a multi-level certification stack.

- **It is proctored:** Delivered via ProctorFree. 60 questions, 120 minutes, live supervision. No Claude, docs, tabs, or tools allowed.
- **It tests architecture, not trivia:** Uses realistic production scenarios to test design calls. Wrong answers are plausible real-world mistakes.
- **It carries enterprise weight:** Massive adoption by firms like Accenture, Cognizant, and Deloitte makes this a baseline expectation for AI architects.

## 👤 Who Is This Certification For?
**Target Audience:** Solution architects with ≥6 months of hands-on production experience with the Claude API, Claude Code, Claude Agent SDK, and Model Context Protocol (MCP).

> [!check] **You are a strong fit if you:**
> - Design agentic systems using the Claude Agent SDK (multi-agent orchestration).
> - Configure Claude Code for teams (`CLAUDE.md`, custom slash commands).
> - Build MCP integrations for external tools/data.
> - Make daily production decisions on context management, costs, and failure recovery.

> [!warning] **Wait to take the exam if you:**
> - Are still learning Claude API fundamentals.
> - Primarily use Claude through the chat interface.
> - Haven't shipped a production application with Claude.

## 📊 The Five Exam Domains

| Domain | Weight | Key Topics to Know |
| :--- | :---: | :--- |
| **1. Agentic Architecture & Orchestration** | **27%** | Agentic loops, multi-agent coordinator-subagent patterns, session state, task decomposition, hub-and-spoke models. *Core loop:* send request → check `stop_reason` → execute tool → return result → repeat. |
| **2. Tool Design & MCP Integration** | **18%** | MCP primitives (tools, resources, prompts). Tool descriptions, error responses (`isError`, `isRetryable`, `errorCategory`), `.mcp.json`, tool scoping. |
| **3. Claude Code Configuration & Workflows** | **20%** | `CLAUDE.md` hierarchy, `.claude/rules/` glob patterns, slash commands, plan mode vs direct execution, `-p` flag for CI/CD, `--output-format json`. |
| **4. Prompt Engineering & Structured Output** | **20%** | Few-shot prompting, validation-retry loops, Message Batches API (50% cost savings, 24hr window), multi-pass review. *Note:* `tool_use` with JSON schema guarantees syntax, not semantics. |
| **5. Context Management & Reliability** | **15%** | Long-context preservation, handoff patterns, confidence calibration, escalation, error propagation. |

> [!tip] Domains 1 & 5 together make up 42% of the exam. Prioritize agentic architecture and context management if time is short!

## 🚫 The 7 Anti-Patterns You Must Memorize
The distractors on the exam are plausible architectural mistakes. Memorize these anti-patterns:

1. **Prompt-based enforcement for critical rules**
   - ❌ *Wrong:* Using system prompts for security/formatting. 
   - ✅ *Correct:* Use programmatic hooks and deterministic validation.
2. **Self-reported confidence for escalation**
   - ❌ *Wrong:* Routing to human based on model's low confidence. 
   - ✅ *Correct:* Use deterministic threshold logic.
3. **Batch API for blocking workflows**
   - ❌ *Wrong:* Routing everything to Batch API to save money. 
   - ✅ *Correct:* Real-time API must be used for user-facing/blocking workflows (Batch has no SLA).
4. **Larger context window = better attention**
   - ❌ *Wrong:* Increasing context to reduce attention dilution. 
   - ✅ *Correct:* Split processing into focused, per-file passes.
5. **Silent failure on subagent error**
   - ❌ *Wrong:* Returning empty results on failure. 
   - ✅ *Correct:* Return structured error context for recovery.
6. **All tools available to all agents**
   - ❌ *Wrong:* Global tool access. 
   - ✅ *Correct:* Scope tools to specific roles to prevent reasoning overload.
7. **Flat multi-agent topology**
   - ❌ *Wrong:* All agents talking to all agents. 
   - ✅ *Correct:* Hub-and-spoke design with a central coordinator.

## 🗺️ Preparation Roadmap
- **Week 1: Foundations** - *Claude 101*, *Building Applications with the Claude API* (8+ hr flagship course).
- **Week 2: Claude Code Hands-On** - Install Claude Code, configure `CLAUDE.md`, run CI/CD. *Claude Code in Action* (Anthropic Academy), *Claude Code on Coursera*.
- **Week 3: MCP & Tool Design** - Build an MCP server. *Intro to MCP*, *MCP Advanced Topics*.
- **Week 4: Prompt Engineering & Structured Output** - Focus on validation-retry, Batch API tradeoffs, multi-pass patterns.
- **Week 5: Multi-Agent Systems & Context Management** - Coordinator-subagent patterns, `Task` tool, `PostToolUse` hooks, context optimization.
- **Week 6+: Practice Exams & Review** - Study the 12 sample questions in Exam Guide. Take 60-question practice exam (Aim for >900/1000).

## 🗓️ Exam Day: What to Expect
- **Before:** Block 2.5 hours. Ensure ProctorFree requirements are met (webcam, mic, clean desk, single monitor).
- **During:** 60 scenario-based questions (drawn from 4 of 6 random scenario contexts). ~2 minutes per question. Flag and return to hard ones. 
- **After:** Scaled score of 100–1,000. **Passing score is 720.**
