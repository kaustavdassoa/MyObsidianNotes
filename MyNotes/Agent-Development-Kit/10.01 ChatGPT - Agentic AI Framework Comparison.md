🧠 **Architect’s Recommendation Framework**
===========================================

Use this **decision tree mindset**:

* * *

1️⃣ Start with your SYSTEM TYPE
-------------------------------

*   **RAG / Search system →** Haystack
*   **Simple LLM app →** LangChain / OpenAI SDK
*   **Agent system → continue ↓**

* * *

2️⃣ Agent Complexity
--------------------

*   **Single agent →** OpenAI SDK / LangChain
*   **Multi-agent →**
    *   Experimental → AutoGen / CrewAI
    *   Production → LangGraph / Google ADK

* * *

3️⃣ Control vs Autonomy
-----------------------

*   Need **deterministic workflows** → **LangGraph / Semantic Kernel**
*   Need **autonomous agents** → **AutoGen / CrewAI**
*   Need **hybrid** → **LangGraph / Google ADK**

* * *

4️⃣ Enterprise Constraints
--------------------------

*   **Strict governance / compliance →**
    *   Google ADK
    *   Semantic Kernel
*   **Cloud alignment**
    *   Azure → Semantic Kernel
    *   GCP → Google ADK

* * *

5️⃣ Scalability & Reliability Needs
-----------------------------------

*   **High-scale production →**
    *   LangGraph (best OSS choice)
    *   Google ADK (enterprise choice)
*   **Prototype / MVP →**
    *   LangChain
    *   CrewAI

* * *

6️⃣ Vendor Strategy
-------------------

*   Avoid lock-in → LangGraph / LangChain / Haystack
*   OK with ecosystem lock → Google ADK / OpenAI SDK / Semantic Kernel
