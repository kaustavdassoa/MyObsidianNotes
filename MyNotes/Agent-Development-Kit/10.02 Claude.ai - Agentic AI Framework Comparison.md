|Dimension|LangGraph|LangChain|CrewAI|Google ADK|AutoGen|Semantic Kernel|OpenAI Agents SDK|

|**State Management**|First-class; typed StateGraph with reducers; full state persists across nodes|Minimal built-in state; memory abstracted separately|Task output passing; agent memory optional|Session service; stateful by default; built-in session persistence|Conversational message history as state; limited beyond that|Context object per conversation; memory plugins available|Thread-based state; run-level state; OpenAI handles persistence|

## Architect's Recommendation Framework

### Step-by-Step Framework Selection Guide

```
STEP 1 — Determine Deployment Constraints
├── Must run on GCP / Vertex AI?
│   └── ✅ → Google ADK (first choice); fallback: LangGraph on Cloud Run
├── Must run on Azure / Microsoft ecosystem?
│   └── ✅ → Semantic Kernel
├── Must be on-prem / self-hosted?
│   └── ✅ → LangGraph or AutoGen (OpenAI SDK is out)
└── Cloud-agnostic / any → Continue to Step 2

STEP 2 — Assess Workflow Complexity
├── Simple chatbot / RAG / document Q&A?
│   └── ✅ → LangChain (fastest); or OpenAI Agents SDK (if OpenAI-only)
├── Multi-agent crew for content / research tasks?
│   └── ✅ → CrewAI (quickest POC); graduate to LangGraph for production
├── Complex stateful workflow with cycles / branching / approvals?
│   └── ✅ → LangGraph (no competition here)
└── Autonomous code execution / research agent?
    └── ✅ → AutoGen

STEP 3 — Assess Team Profile
├── .NET / Enterprise Microsoft developers?
│   └── ✅ → Semantic Kernel
├── Python engineers comfortable with graph design?
│   └── ✅ → LangGraph
├── Junior / full-stack developers wanting quick results?
│   └── ✅ → CrewAI → OpenAI Agents SDK
└── ML Researchers building autonomous systems?
    └── ✅ → AutoGen

STEP 4 — Assess Compliance / Regulatory Requirements
├── HIPAA / FedRAMP / SOC2 required?
│   ├── On Azure → Semantic Kernel + Azure AI
│   ├── On GCP → Google ADK + Vertex AI
│   └── Cloud-agnostic → LangGraph + LangSmith Enterprise
└── No compliance constraints → skip step

STEP 5 — Assess Model Strategy
├── OpenAI only + simple flows?
│   └── ✅ → OpenAI Agents SDK
├── Multi-model (OpenAI + Anthropic + Gemini + open-source)?
│   └── ✅ → LangGraph or LangChain (best model coverage)
└── Gemini-first / GCP?
    └── ✅ → Google ADK

STEP 6 — Assess Production Maturity Requirements
├── POC / prototype (< 4 weeks)?
│   └── ✅ → CrewAI → LangChain → OpenAI Agents SDK
├── Production in 3–6 months?
│   └── ✅ → LangGraph or Google ADK
└── Enterprise production with compliance + audit trail?
    └── ✅ → Semantic Kernel (Azure) or Google ADK (GCP)
```

### The Honest Summary in Plain English

|Scenario|Recommendation|Reasoning|
|---|---|---|
|"I need a working demo by Friday"|CrewAI or OpenAI Agents SDK|Lowest friction to multi-agent demo|
|"We're building production agents on AWS, multi-model"|LangGraph + LangSmith|Best control, observability, model flexibility|
|"Our company is all-in on Azure"|Semantic Kernel|Azure native, compliance, .NET ecosystem|
|"We're on GCP and need enterprise-grade"|Google ADK|Vertex AI native, GCP SLAs, safety filters|
|"We need autonomous agents that write and run code"|AutoGen|Best code-execution agent patterns|
|"We need complex approval workflows and audit trails"|LangGraph|HITL, checkpointing, and LangSmith traces|
|"We just use OpenAI and want to ship fast"|OpenAI Agents SDK|Thinnest abstraction, best DX for this constraint|
|"We need 100+ integrations in a RAG pipeline"|LangChain|Richest ecosystem for integration-heavy systems|
