# Google ADK - Agent Configuration

Using [[generate_content_config]] one can define the overall [[Agent Configuration]], which can help in strictly controlling the agent's behavior, output format, and safety boundaries. 

> [!note] Agent Behavior
> Carefully tuning your configuration parameters is essential for moving an [[LlmAgent]] from a generic chatbot to a focused, reliable programmatic tool.

## Generate Content Config Parameters

Below are the possible configurations that can be passed into `types.GenerateContentConfig` to govern the model's generation process:

| Configuration Parameter | Description | Allowed Values / Types |
| :--- | :--- | :--- |
| **`temperature`** | Controls the randomness of the output. Lower values make the output more deterministic and focused, while higher values make it more creative and diverse. | Float: `0.0` to `2.0` |
| **`top_p`** | Nucleus sampling. The model considers the smallest set of tokens whose cumulative probability exceeds `top_p`. | Float: `0.0` to `1.0` |
| **`top_k`** | The model considers only the top `k` most probable tokens for the next step. | Integer: `>= 1` |
| **`max_output_tokens`** | The maximum number of tokens to include in a generated candidate. | Integer: `> 0` |
| **`stop_sequences`** | A list of strings that will immediately stop output generation if encountered. | List of Strings (Max 5) |
| **`presence_penalty`** | Penalizes tokens if they have appeared at least once so far, encouraging the model to introduce new topics. | Float: `-2.0` to `2.0` |
| **`frequency_penalty`** | Penalizes tokens based on exactly how often they have appeared, reducing repetition of the same lines. | Float: `-2.0` to `2.0` |
| **`response_mime_type`** | Forces the model to output in a specific format structure. | String: e.g., `"text/plain"`, `"application/json"` |
| **`response_schema`** | Defines a strict JSON schema that the model's output must adhere to (requires JSON mime type). | Schema Object / Dictionary |
| **`safety_settings`** | A list of harm categories and their corresponding block thresholds to prevent unsafe content generation. | List of `SafetySetting` objects |
| **`system_instruction`** | Foundational instructions that guide the model's underlying persona, rules, and overall behavior constraints. | String |
| **`tools`** | A list of external tools (e.g., Functions, Search) the model is explicitly allowed to call to gather information. | List of `Tool` objects |
| **`tool_config`** | Defines how the model should behave regarding the provided tools (e.g., forcing a specific function call or allowing auto selection). | `ToolConfig` object |
## Example LlmAgent Definition

The following Python code demonstrates how to instantiate an [[LlmAgent]] while applying specific guardrails using the configuration parameters.

```python 
# Define the agent
root_agent = LlmAgent(
    name="history_agent",
    model="gemini-2.5-flash",
    description="""An agent that helps with history lessions""",
    instruction="""
    When asked about a topic, summarize the answer in bullet points and  provide a 5 lines crisp summary at the end
     """,
    generate_content_config=types.GenerateContentConfig(
        temperature=0.2,
        max_output_tokens=4000,
        safety_settings=[
            types.SafetySetting(
                category=types.HarmCategory.HARM_CATEGORY_DANGEROUS_CONTENT,
                threshold=types.HarmBlockThreshold.BLOCK_LOW_AND_ABOVE,
            )
        ]
    )
)
