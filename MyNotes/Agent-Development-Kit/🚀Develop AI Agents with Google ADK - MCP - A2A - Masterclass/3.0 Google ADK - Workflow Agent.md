### Parallel Agents 

**Root Agent : Marketing Agent** 
Root (main) agent that call its sub agent in parallel. This speed up the operation as both the agents are working in parallel. 

```python 
root_agent = ParallelAgent(
    name="marketing_agent",
    model="gemini-2.5-flash",
    description="Runs multiple parallel agents to create a brand marketing inputs",
    sub_agents=[brand_story_agent,hashtag_agent],
)
```

**Sub-Agent : Brand Story**
Sub Agent to create brand story.

```python 
brand_story_agent = Agent(
    name="brand_story_agent",
    model="gemini-2.5-flash",
    description="An agent who creates a brand story on a given topic.",
    instruction="""
    You are an agent who specializes in creating brand story. Please make sure     the story is relevent to current generation and it is limited to 5 lines       and crisp in nature
    """,
)
```
