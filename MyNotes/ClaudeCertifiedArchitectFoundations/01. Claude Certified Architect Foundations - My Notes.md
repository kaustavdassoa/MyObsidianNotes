# **Claude Certified Architect (Foundations): Exam Guide and Blueprint** 

Link : https://claudecertificationguide.com/blog/claude-certified-architect-foundations-exam-guide

## **The five Domains** 

1.  Agentic Architecture & Orchestration  - Agentic loops, orchestration patterns, guardrails, the Agent SDK
2. Tools Design & MCP Integration - Tool schemas, MCP servers and clients, tool routing
3. Claude Code Configuration & workflow  - Settings hierarchy, `CLAUDE.md`, hooks, permissions, CI/CD
4. Prompt Engineering & Structured Output - System prompts, few-shot patterns, output validation
5. Context Management & Reliability - Context windows, caching, long conversations, reliability

## **Exam Scenarios** 

- Customer Support Resolution Agent
- Code Generation with Claude Code 
- Multi-Agent Research System 
- Developer Productivity with Claude 
- Claude Code for CI/CD 
- Structured Data Extraction

A live exam form uses four of these six scenarios, with roughly 15 questions attached to each selected scenario.
