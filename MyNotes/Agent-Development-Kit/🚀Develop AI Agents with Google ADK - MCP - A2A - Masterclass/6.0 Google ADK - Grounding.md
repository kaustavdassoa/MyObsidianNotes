# Google ADK - Grounding

> [!info] Understanding Grounding
> **[[Grounding]]** is the process of tethering a Large Language Model (LLM) to a specific, verifiable source of truth or external dataset, rather than relying solely on the model's pre-trained parametric memory. 
> 
> **In detail:** By default, LLMs predict the next most likely word based on patterns learned during training, which can lead to hallucinations (confident but incorrect statements) when asked about niche, proprietary, or highly recent information. Grounding interrupts this by fetching relevant contextual data (like a company policy document or a live web search) and injecting it into the prompt. The LLM is then instructed to synthesize its answer *only* from the provided context, significantly increasing accuracy, ensuring data freshness, and allowing the model to provide verifiable citations for its claims.

---

## Available Grounding Options

When building applications with [[Google ADK]] or LLMs in general, several grounding strategies can be employed:

* **[[RAG]] (Retrieval-Augmented Generation):** Converting your documents into vector embeddings and storing them in a vector database. When a user asks a query, the system retrieves the most mathematically similar text chunks and feeds them to the LLM.
* **Web Grounding:** Connecting the model to a search engine (like Google Search) to retrieve real-time data from the public internet.
* **Enterprise Search Grounding:** Using managed enterprise search platforms (like Vertex AI Search) to query internal corporate wikis, codebases, or document repositories.
* **Structured Data Grounding:** Querying SQL databases, Knowledge Graphs, or external APIs to inject highly structured, deterministic data into the model's context.

## Leveraging Vertex AI for Grounding in Google ADK

> [!summary] Vertex AI Grounding Capabilities
> [[Vertex AI]] provides a robust, native ecosystem for grounding that [[Google ADK]] can seamlessly tap into. Instead of building a custom vector database from scratch, developers can use managed Vertex AI features.

**Available Features and Integrations in Vertex AI:**

1.  **Grounding with Google Web Search:** Natively allows the agent to search the public internet for up-to-date information, returning search snippets as context.
2.  **Vertex AI Search (Data Stores):** The primary engine for grounding on your own data. It supports ingestion of unstructured data (PDFs, HTML, TXT), structured data (JSON, CSV), and website domains.
3.  **Third-Party Tool & System Connections:** Through Vertex AI Extensions and Data Store connectors, you can ground agents on external platforms, including:
    * **Cloud Storage:** Google Cloud Storage (GCS) buckets.
    * **Databases:** BigQuery, AlloyDB, Cloud SQL.
    * **Enterprise Apps:** Jira, Confluence, Salesforce, ServiceNow.
    * **Third-Party Vector DBs:** Pinecone, pgvector.

## Implementation: Grounding on an Instruction Manual

> [!todo] High-Level Steps to Upload an Instruction Manual
> To ground your [[LlmAgent]] on a specific instruction manual (e.g., a PDF), follow these steps in Google Cloud:
> 1. **Upload:** Upload your instruction manual PDF to a Google Cloud Storage (GCS) bucket.
> 2. **Create Data Store:** Navigate to Vertex AI Search and Conversation and create a new "Data Store". Select "Cloud Storage" as your source.
> 3. **Sync:** Point the Data Store to your GCS bucket and allow Vertex AI to parse, chunk, and index the manual.
> 4. **Retrieve ID:** Once indexed, copy the Data Store ID (it will look like a long Google Cloud resource path).

> [!code] Sample Agent Code for Grounding
> Below is a conceptual implementation showing how to define an [[LlmAgent]] in Google ADK that utilizes a Vertex AI Data Store (containing your instruction manual) for grounding.

```python 
from google.genai import types

# Define the agent with Vertex AI Search Grounding
root_agent = LlmAgent(
    name="manual_assistant_agent",
    model="gemini-2.5-flash",
    description="An agent that helps users troubleshoot using the official instruction manual.",
    instruction="""
    You are a technical support agent. You must answer user queries by strictly relying on the information retrieved from the connected instruction manual datastore. Do not invent answers. If the information is not in the manual, state that you do not know. Always cite the document snippet you used.
    """,
    # The tools array connects the agent to the Vertex AI Grounding mechanism
    tools=[
        types.Tool(
            retrieval=types.Retrieval(
                vertex_ai_search=types.VertexAISearch(
                    # Replace with your actual Data Store resource path
                    datastore="projects/YOUR_PROJECT_ID/locations/global/collections/default_collection/dataStores/YOUR_DATASTORE_ID"
                )
            )
        )
    ]
)
